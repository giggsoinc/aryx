Smart understand (model-agnostic)

  • Uses Settings answer model via llm_runtime — never hardcodes Gemini.
  • Returns: summary, brief (6 fields), graph_plan (primary + dimension types + relationships), follow_ups, suggested_documents.
  • Offline heuristic fallback if the model is unavailable (still multi-type for bank-like CSVs).
  • Ontology packs are optional; not required for a first plan.
